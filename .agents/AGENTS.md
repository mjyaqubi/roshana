# Project Instructions

## History Documentation
- For every prompt and response turn in this repository, document the user request and assistant response under `docs/history/`.
- Use a 3-digit zero-padded sequential prefix format (e.g., `001_title.md`, `002_title.md`, `003_title.md`).

## Implementation Plans Documentation
- Whenever an implementation plan is created, store it under `docs/plans/` using a 3-digit zero-padded sequential prefix format (e.g., `001_title.md`, `002_title.md`, `003_title.md`).

## Git Commit and Push
- At the end of every prompt and response turn in this repository, automatically stage all modified and created files (`git add .`), create a descriptive git commit (`git commit -m "..."`), and push the changes to the remote repository (`git push`).
